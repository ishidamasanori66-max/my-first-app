# コラム：ブラウザ操作AIエージェントの動向

## はじめに

2024〜2025年にかけて、AIがブラウザを自律的に操作する新しいカテゴリのツールが登場しています。本コラムでは、主要な3つのツールを紹介し、本カリキュラムとの関係を整理します。

---

## 主要ツール一覧

| ツール | 提供元 | リリース | 状況 |
|---|---|---|---|
| ChatGPT Operator | OpenAI | 2025年1月 | Pro限定（$200/月） |
| Claude Cowork | Anthropic | 2025年（予定） | 開発中 |
| Gemini Auto Browse | Google | 2025年 | 順次展開中 |

---

## ChatGPT Operator / Agent

### 概要

```
OpenAI が提供するブラウザ自動操作エージェント。
ChatGPT Pro プラン（$200/月）で利用可能。
```

### できること

```
・Webサイトの閲覧・操作
・フォームへの入力
・予約・注文などの代行
・複数サイトをまたいだ情報収集
・ログインが必要なサイトの操作（認証情報を渡す）
```

### 具体例

```
ユーザー: 「来週の金曜日、新宿で4人で使える個室居酒屋を予約して」

Operator:
  1. グルメサイトを開く
  2. 条件で検索
  3. 候補を比較
  4. 空き状況を確認
  5. 予約フォームに入力
  6. 予約完了を報告
```

### 現在の制限

```
・月額$200と高額（Pro限定）
・日本では一部機能が制限
・複雑な操作は失敗することがある
・決済を伴う操作は人間の確認が必要
・サイトによってはブロックされる
```

## Claude Cowork

### 概要

```
Anthropic が開発中のブラウザ操作エージェント。
Claude の「Computer Use」機能を発展させたもの。
```

### 技術的背景

```
Claude の Computer Use（2024年発表）:
・スクリーンショットを見て画面を理解
・マウス・キーボード操作をコマンドで実行
・OSレベルでのPC操作が可能

Cowork はこれをブラウザに特化・洗練させたもの
```

### 想定される機能

```
・Webブラウザの自律操作
・業務タスクの代行
・他のClaude機能（コード生成等）との連携
・チームでの共同作業支援
```

### 現在の状況

```
・正式リリース前（2025年2月時点）
・Computer Use はAPI経由で利用可能
・Cowork としての一般提供時期は未定
```

## Gemini Auto Browse

### 概要

```
Google が提供するブラウザ自動操作機能。
Gemini（旧Bard）の拡張機能として提供。
```

### できること

```
・Webページの閲覧・情報抽出
・Google サービスとの連携（Gmail, Calendar等）
・検索結果の要約・分析
・複数ページの巡回・情報収集
```

### 特徴

```
・Google アカウントとの統合
・Google Workspace との親和性
・Chrome ブラウザとの連携
・比較的低コストで利用可能
```

### 現在の制限

```
・機能が限定的（Operatorほど自律的ではない）
・日本語対応が不完全な部分あり
・複雑なフォーム操作は苦手
・Google 以外のサービスとの連携は限定的
```

## 本カリキュラムとの関係

### なぜメインカリキュラムに含めないのか

```
1. 学習目的との矛盾
   ─────────────────
   カリキュラムの目的: 「自分で作れる力」を育てる
   これらのツール: 「作らなくても済む」方向

   → コードを書く動機が薄れるリスク


2. 変化が激しい
   ─────────────────
   ・UIや機能が頻繁に変わる
   ・半年後には操作方法が変わっている可能性
   ・カリキュラムとして教材化しにくい


3. 安定性・信頼性
   ─────────────────
   ・複雑な操作は失敗することがある
   ・業務で使うには不安定
   ・エラー時に自分で対処できない


4. コスト
   ─────────────────
   ・Operator は月額$200
   ・中小企業向けカリキュラムとしてはハードルが高い
```

### カリキュラムで身につけるスキルとの比較

```
【これらのツールでできること】
・Webサイトの閲覧・操作
・フォーム入力の自動化
・情報収集

【ゴールド/プラチナで学ぶスキルでできること】
・API連携による堅牢な自動化
・Edge Functions でのサーバー処理
・AIエージェントの自作（LangChain）
・より柔軟で信頼性の高い自動化

→ 本カリキュラムのスキルの方が応用範囲が広い
→ ツールが対応できないケースも自分で解決できる
```

## これらのツールの将来性

### 成熟した場合の可能性

```
・業務の定型作業を大幅に効率化
・非エンジニアでも高度な自動化が可能
・コードを書く必要性が減少

→ 2〜3年後には状況が大きく変わる可能性
```

### カリキュラム修了者の優位性

```
これらのツールが普及しても、
本カリキュラムで身につけた力は活きる：

1. ツールの限界を理解できる
   → 何ができて何ができないか判断できる

2. ツールが対応できないケースに対処できる
   → 自分でコードを書いて解決

3. ツールを「使いこなす」側になれる
   → APIが公開されたら自社システムに組み込める

4. 複合的な解決策を設計できる
   → ツール＋自作コードの組み合わせ
```

## 実務での使い分け

### 現時点での推奨

```
【これらのツールを使うべきケース】
・一回限りの調査タスク
・定期的でない情報収集
・試行錯誤的な探索作業
・個人の生産性向上

【自作すべきケース（本カリキュラムのスキル）】
・定期的に実行する業務
・業務フローに組み込む処理
・信頼性が求められる処理
・複雑なビジネスロジックを含む処理
```

### 将来的な使い分け

```
【ツールが成熟した場合】
・シンプルな定型タスク → ブラウザAIエージェント
・複雑・重要なタスク → 自作システム

本カリキュラムのスキルがあれば、
状況に応じて適切な判断ができる
```
