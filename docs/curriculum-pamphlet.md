# AI伴走型DX人材育成プログラム

## 〜 中小企業の「内製力」を育てる 4ステップカリキュラム 〜

---

## こんな課題を抱えていませんか？

```
□ システム開発を外注すると高い、でも内製できる人がいない
□ Excel作業に時間を取られ、本来の業務に集中できない
□ 社内にバラバラなシステムがあり、データが連携できていない
□ IT担当者が1人で、その人が辞めたら何も分からなくなる
□ 「DX」と言われても、何から始めれば良いか分からない
```

**このプログラムは、これらの課題を「自社で解決できる人材」を育てます。**

## ブロンズ：個人の業務改善

### 「毎月同じ作業を繰り返していませんか？」

```
【Before】
・各店舗のExcelを手作業で集計 → 3時間
・複数ファイルのデータ結合 → コピペで1時間
・集計ミスが発生してやり直し

【After】
・コードを実行するだけ → 5分で完了
・何度でも再利用可能
・ミスがなくなる
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| Python | プログラミング言語（データ処理の標準） |
| Pandas | ファイル入出力（Excel/CSVの読み書き） |
| sqlite3 | データ処理（SQLでExcel操作を自動化） |
| matplotlib | データ可視化（グラフ作成） |
| Google Colab | ブラウザ上の実行環境（インストール不要） |
| Gemini | AIアシスタント（分からないことはAIに聞く） |

### ポイント

```
✓ 環境構築ゼロ（ブラウザだけで開始）
✓ 完全無料で受講可能
✓ プログラミング未経験でもOK
✓ SQLを学ぶことでシルバーへスムーズに移行
✓ AIに聞きながら進めるので挫折しにくい
```

### 学習時間の目安

```
週5時間ペース → 約1.5〜2ヶ月（32〜42時間）
週10時間ペース → 約1ヶ月弱
```

## シルバー：組織の業務プロセス改善

### 「現場に合ったアプリを自分で作れるようになる」

```
【Before】
・データ入力が紙やExcel → メールで送付 → 集計
・市販のシステムは帯に短し襷に長し
・外注すると300万円〜、保守費も毎月

【After】
・Webフォームから直接入力 → 自動でDB蓄積
・現場のニーズに100%合ったアプリを自作
・修正も自分ですぐ対応
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| React (Vite) | Webアプリのフロントエンド |
| Supabase | データベース・認証・ストレージ（オールインワン） |
| GitHub Codespaces | ブラウザ上の開発環境 |
| Claude Code | AI伴走開発（対話しながらコードを書く） |

### 作れるようになるもの

```
・顧客管理（CRM）
・在庫管理
・予約システム
・勤怠管理
・承認ワークフロー
・売上ダッシュボード
```

### ポイント

```
✓ PCにコードを置かない（退職・PC故障に強い）
✓ ブラウザだけで開発〜運用まで完結
✓ AIと対話しながら開発（1人でも大丈夫）
✓ ブロンズで学んだSQLがそのまま使える
```

## ブロンズとシルバーの違い

### 改善の対象が異なる

```
【ブロンズ】個人の業務改善
                    ┌─────────────────┐
既存のExcel ───────→│ 集計・分析・可視化 │───→ レポート
                    └─────────────────┘
                         ↑
                    ここを効率化


【シルバー】組織の業務プロセス改善
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  入力フォーム  │ ──→ │  データベース  │ ──→ │ 自動集計・表示 │
└─────────────┘      └─────────────┘      └─────────────┘
    ↑                     ↑                     ↑
  Web化              Excel脱却              リアルタイム

    └───────────── 業務プロセス全体を改善 ─────────────┘
```

### 具体例：日報業務

```
【ブロンズ（個人の効率化）】
・各店舗が送ってきたExcelを自動集計
・Before: 手作業3時間 → After: 5分
・でも「Excelを作って送る」作業は残る

【シルバー（組織のプロセス改善）】
・各店舗がWebフォームから直接入力
・データは即座にDBに蓄積
・本部はリアルタイムでダッシュボード確認
・「Excelを送る」という業務自体がなくなる
```

### キャッチコピー

```
【ブロンズ】「あなたの3時間を5分に」
【シルバー】「Excelを送る業務をなくす」
```

## カリキュラムの特徴

### 1. 積み上げ式の一貫したカリキュラム

```
ブロンズ: Python + SQL の基礎
    ↓
シルバー: Supabase（PostgreSQL）= 同じSQL
    ↓
ゴールド: Edge Functions で API連携
    ↓
プラチナ: Python + LangChain で AI エージェント

→ 各ステージの知識が次のステージで活きる
→ 無駄な学習がない
```

### 2. AI伴走で挫折しにくい

```
【従来のプログラミング学習】
・エラーが出る → 意味が分からない → 挫折

【AI伴走学習】
・エラーが出る → AIに聞く → 解決策を教えてもらう → 続けられる

使用するAI:
・ブロンズ: Gemini（Google環境との親和性）
・シルバー〜プラチナ: Claude（コード生成・ファイル編集に強い）
```

### 3. ローカルPCにコードを置かない

```
【従来の問題】
・担当者退職 → 環境構築からやり直し
・PC故障 → コード消失
・セキュリティ → コードが個人PCに散在

【このカリキュラム】
・退職 → 新担当がログインするだけ
・PC故障 → 別PCで継続
・セキュリティ → コードは会社のGitHubに集約
```

### 4. 低コスト・低運用負担

| ステージ | ツール費用（目安） |
|---|---|
| ブロンズ | 無料 |
| シルバー | Claude Pro $20/月（推奨） |
| ゴールド | 同上 + API従量課金（少額） |
| プラチナ | Claude API 従量課金 |

```
【外注との比較】
・SIer発注: 初期300万円〜 + 保守月5〜10万円
・このカリキュラム: 教育費 + ツール月数千円

→ 長期的に見て圧倒的なコスト優位性
```

## よくある質問

### Q: プログラミング未経験でも大丈夫ですか？

```
A: はい、ブロンズからスタートすれば大丈夫です。
   Excelが使えるレベルであれば、AIの助けを借りながら
   着実にスキルを身につけられます。
```

### Q: 全ステージを修了しないと意味がないですか？

```
A: いいえ、各ステージで十分な価値があります。
   ・ブロンズだけでも日々の業務効率化が可能
   ・シルバーまでで自社アプリの内製化が可能
   ・必要に応じてゴールド・プラチナへ進めます
```

### Q: ブロンズとシルバー、どちらから始めるべきですか？

```
A: 基本はブロンズからの受講をお勧めします。
   ・SQLの基礎がシルバーで活きる
   ・小さな成功体験が次への意欲になる

   ただし、すでにSQLの知識がある方や、
   すぐにWebアプリが必要な場合はシルバーからも可能です。
```

### Q: 学んだ後、継続的なサポートはありますか？

```
A: 開発環境がすべてクラウド上にあるため、
   ・困ったらAI（Claude Code）に質問
   ・コードはGitHubに残っているので引き継ぎ容易
   ・必要に応じて追加のコンサルティングも可能
```

### Q: セキュリティは大丈夫ですか？

```
A: はい、以下の対策を取っています。
   ・コードはGitHub（企業管理下）に集約
   ・Supabaseは業界標準のセキュリティ
   ・機密データはマスキング処理
   ・医療系など特殊要件はハイブリッド構成で対応可能
```
