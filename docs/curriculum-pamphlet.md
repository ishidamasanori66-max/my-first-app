# AI伴走型DX人材育成プログラム

## 〜 中小企業の「内製力」を育てる 5ステップカリキュラム 〜

---

## こんな課題を抱えていませんか？

```
□ システム開発を外注すると高い、でも内製できる人がいない
□ Excel作業に時間を取られ、本来の業務に集中できない
□ 社内にバラバラなシステムがあり、データが連携できていない
□ IT担当者が1人で、その人が辞めたら何も分からなくなる
□ 「DX」と言われても、何から始めれば良いか分からない
```

**このプログラムは、これらの課題を「自社で解決できる人材」を育てます。**

---

## プログラムの全体像

```
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│   ブロンズ → シルバー → ゴールド → プラチナ → ダイヤモンド       │
│                                                                      │
│   Excel自動化  業務アプリ  システム連携  顧客接点   事業価値創出   │

│                                                                      │
│   ──────── 内から外へ、そしてデータから未来へ ──────── │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

| ステージ | キャッチコピー | 改善対象 | 解決できること |
|:---:|---|---|---|
| **ブロンズ** | 「あなたの3時間を5分に」 | 個人の業務 | Excel作業を5分で終わらせる |
| **シルバー** | 「Excelを送る業務をなくす」 | 組織の業務プロセス | データ収集からデジタル化 |

## ブロンズ：個人の業務改善

### 「毎月同じ作業を繰り返していませんか？」

```
【Before】
・各店舗のExcelを手作業で集計 → 3時間
・複数ファイルのデータ結合 → コピペで1時間
・集計ミスが発生してやり直し

【After】
・コードを実行するだけ → 5分で完了
・何度でも再利用可能
・ミスがなくなる
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| Python | プログラミング言語（データ処理の標準） |
| Pandas | ファイル入出力（Excel/CSVの読み書き） |
| Pydantic | データ検証（型チェック・バリデーション） |
| sqlite3 | データ処理（SQLでExcel操作を自動化） |
| Google Colab | ブラウザ上の実行環境（インストール不要） |
| Gemini | AIアシスタント（分からないことはAIに聞く） |

※ オプション：matplotlib（グラフ作成）、openpyxl（書式付きExcel出力）

### ポイント

```
✓ 環境構築ゼロ（ブラウザだけで開始）
✓ 完全無料で受講可能
✓ プログラミング未経験でもOK
✓ SQLを学ぶことでシルバーへスムーズに移行
✓ Pydanticでデータ検証スキルを習得（シルバー以降でも活用）
✓ AIに聞きながら進めるので挫折しにくい
✓ グラフ・書式設定はオプション（シルバー進学者は不要）
```

### 学習時間の目安

```
週5時間ペース → 約1.5〜2ヶ月（32〜42時間）
週10時間ペース → 約1ヶ月
```

## シルバー：組織の業務プロセス改善

### 「現場に合ったアプリを自分で作れるようになる」

```
【Before】
・データ入力が紙やExcel → メールで送付 → 集計
・市販のシステムは帯に短し襷に長し
・外注すると300万円〜、保守費も毎月

【After】
・Webフォームから直接入力 → 自動でDB蓄積
・現場のニーズに100%合ったアプリを自作
・修正も自分ですぐ対応
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| AppSheet | ノーコードでプロトタイピング |
| Django | Webアプリフレームワーク（Python製） |
| HTMX | 動的UI（JavaScriptを書かずに実現） |
| Supabase | PostgreSQL + JSONB + Realtime（データベース） |
| Looker Studio | 経営ダッシュボード |
| GitHub Codespaces | ブラウザ上の開発環境 |
| GitHub Copilot | AI伴走開発（インライン補完 + チャット） |

### 作れるようになるもの

```
・顧客管理（CRM）
・在庫管理
・予約システム
・勤怠管理
・承認ワークフロー
・リアルタイム売上ダッシュボード
```

### ポイント

```
✓ AppSheetでプロトタイプ → Djangoで本実装の流れ
✓ ブロンズと同じPython（新しい言語を学ばなくてよい）
✓ JSONB + Pydantic でブロンズのスキルがそのまま活きる
✓ Supabase Realtimeでリアルタイム同期
✓ CI/CD（GitHub Actions）で安全にデプロイ
✓ PCにコードを置かない（退職・PC故障に強い）
✓ AIと対話しながら開発（1人でも大丈夫）
```

## カリキュラムの特徴

### 1. 積み上げ式の一貫したカリキュラム

```
ブロンズ: Python + SQL + Pydantic の基礎（個人の業務改善）
    ↓
シルバー: AppSheet → Django + HTMX + Supabase (JSONB + Realtime)（Pythonのまま！）
    ↓
ゴールド: + 外部API連携 + Celery で社内システム統合
    ↓
プラチナ: + 選択モジュール（決済・LINE・AI等）で顧客接点を構築
    ↓
ダイヤモンド: + ML で蓄積データから事業価値を創出

→ 「内から外へ、そしてデータから未来へ」の一貫したストーリー
→ 全5ステージがPython（言語の切り替え不要）
→ ブロンズで学んだPython + SQLが全ステージで活きる
```

### 2. AI伴走で挫折しにくい

```
【従来のプログラミング学習】
・エラーが出る → 意味が分からない → 挫折

【AI伴走学習】
・エラーが出る → AIに聞く → 解決策を教えてもらう → 続けられる

使用するAI:
・ブロンズ: Gemini（Google Colab環境との親和性）
・シルバー〜ダイヤモンド: GitHub Copilot（Codespaces公式統合）
  └ Claude, Gemini, GPT等のモデルを状況に応じて切り替え可能
```

### 3. ローカルPCにコードを置かない

```
【従来の問題】
・担当者退職 → 環境構築からやり直し
・PC故障 → コード消失
・セキュリティ → コードが個人PCに散在

【このカリキュラム】
・退職 → 新担当がログインするだけ
・PC故障 → 別PCで継続
・セキュリティ → コードは会社のGitHubに集約
```

### 4. AIと自動化で品質を確保

```
【従来の品質確保】
・専任QAエンジニアが必要
・テスト計画書を手作業で作成
・テスト実行も手作業
・コストと時間がかかる

【このカリキュラム】
・AIがテストコードを書く
・プッシュするたびに自動テスト
・AIがコードレビュー

```

    ↓

    ↓
従業員：スキーマ拡張＋分析追加（改善）
    ↓
