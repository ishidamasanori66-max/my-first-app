# AI伴走型DX人材育成プログラム

## 〜 中小企業の「内製力」を育てる 4ステップカリキュラム 〜

---

## こんな課題を抱えていませんか？

```
□ システム開発を外注すると高い、でも内製できる人がいない
□ Excel作業に時間を取られ、本来の業務に集中できない
□ 社内にバラバラなシステムがあり、データが連携できていない
□ IT担当者が1人で、その人が辞めたら何も分からなくなる
□ 「DX」と言われても、何から始めれば良いか分からない
```

**このプログラムは、これらの課題を「自社で解決できる人材」を育てます。**

## ブロンズ：Excel業務の自動化

### 「毎月同じ作業を繰り返していませんか？」

```
【Before】
・各店舗のExcelを手作業で集計 → 3時間
・複数ファイルのデータ結合 → コピペで1時間
・集計ミスが発生してやり直し

【After】
・コードを実行するだけ → 5分で完了
・何度でも再利用可能
・ミスがなくなる
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| Python | プログラミング言語（データ処理の標準） |
| Pandas | データ処理（Excelのような表操作をコードで） |
| Google Colab | ブラウザ上の実行環境（インストール不要） |
| Gemini | AIアシスタント（分からないことはAIに聞く） |

### ポイント

```
✓ 環境構築ゼロ（ブラウザだけで開始）
✓ 完全無料で受講可能
✓ プログラミング未経験でもOK
✓ AIに聞きながら進めるので挫折しにくい
```

### 学習時間の目安

```
週5時間ペース → 約2〜3ヶ月
週10時間ペース → 約1〜1.5ヶ月
```

## シルバー：業務アプリ開発

### 「現場に合ったアプリを自分で作れるようになる」

```
【Before】
・市販のシステムは帯に短し襷に長し
・外注すると300万円〜、保守費も毎月
・ちょっとした修正にも追加費用

【After】
・現場のニーズに100%合ったアプリを自作
・ツール費用は月数千円
・修正も自分ですぐ対応
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| React (Vite) | Webアプリのフロントエンド |
| Supabase | データベース・認証・ストレージ（オールインワン） |
| GitHub Codespaces | ブラウザ上の開発環境 |
| Claude Code | AI伴走開発（対話しながらコードを書く） |

### 作れるようになるもの

```
・顧客管理（CRM）
・在庫管理
・予約システム
・勤怠管理
・承認ワークフロー
・売上ダッシュボード
```

### ポイント

```
✓ PCにコードを置かない（退職・PC故障に強い）
✓ ブラウザだけで開発〜運用まで完結
✓ AIと対話しながら開発（1人でも大丈夫）
✓ 自動デプロイで即座に公開
```

## ゴールド：システム統合

### 「バラバラなシステムを繋いで一元管理」

```
【Before】
・予約システム、会計ソフト、決済端末がバラバラ
・各システムからCSV出力 → Excelで手作業集計
・データが散在して全体像が見えない

【After】
・APIでシステム間を自動連携
・データを一元管理ダッシュボードで表示
・定期レポートを自動生成・自動送信
```

### 追加で習得する技術

| 技術 | 役割 |
|---|---|
| Edge Functions | サーバー処理（ビジネスロジック） |
| 外部API連携 | LINE, Slack, freee, Google等と接続 |
| Webhook | イベント駆動処理（◯◯したら△△する） |
| スケジュール実行 | 定期バッチ処理（毎日/毎週自動実行） |

### 連携できるサービス例

```
【通知】     LINE, Slack, メール
【会計】     freee, マネーフォワード
【カレンダー】Google Calendar
【シート】   Google Sheets, スプレッドシート
【AI】       OpenAI (GPT), Claude
【決済】     Stripe, Square
```

### ポイント

```
✓ iPaaSに頼らず自分で作れる力を身につける
✓ 月額課金のツールに依存しない
✓ 独自のロジックも自由に実装可能
✓ シルバーの知識がそのまま活きる
```

## プラチナ：AI社員の導入

### 「AIが自律的に業務を遂行する」

```
【Before】
人間: 「先月の売上分析して」
担当者: データ集計 → 分析 → レポート作成（数時間）

【After】
人間: 「先月の売上分析して」
AI:
  1. DBからデータを取得
  2. 統計分析を実行
  3. グラフを生成
  4. レポートを作成
  5. 改善提案まで出力（数分）
```

### 技術スタック

| 技術 | 役割 |
|---|---|
| Python | プログラミング言語（ブロンズで習得済み） |
| LangChain | AIエージェント開発フレームワーク |
| Claude API | 大規模言語モデル（AIの頭脳） |
| Supabase pgvector | ベクトルDB（社内文書をAIが検索） |

### 実現できること

```
【社内FAQ自動応答】
社員: 「有給の申請方法は？」
AI: 社内マニュアルを検索 → 手順を即座に回答

【顧客対応の自動化】
顧客: 「注文状況を教えて」
AI: DB検索 → 配送確認 → 状況を返信（数秒）

【業務の自動化】
・在庫が閾値を下回ったら自動発注依頼
・定期レポートを自動作成・送信
・問い合わせへの返信案を自動生成
```

### ポイント

```
✓ ブロンズのPythonスキルを発展的に活用
✓ 既存のSupabase構成にそのまま追加可能
✓ 「AIが提案 → 人間が承認」の安全な運用
✓ 社内文書をAIが参照して正確に回答
```

## カリキュラムの特徴

### 1. 積み上げ式の一貫したカリキュラム

```
ブロンズ: Python の基礎（テーブル思考）
    ↓
シルバー: Supabase（PostgreSQL）= 同じテーブル構造
    ↓
ゴールド: Edge Functions で API連携
    ↓
プラチナ: Python + LangChain で AI エージェント

→ 各ステージの知識が次のステージで活きる
→ 無駄な学習がない
```

### 2. AI伴走で挫折しにくい

```
【従来のプログラミング学習】
・エラーが出る → 意味が分からない → 挫折

【AI伴走学習】
・エラーが出る → AIに聞く → 解決策を教えてもらう → 続けられる

使用するAI:
・ブロンズ: Gemini（Google環境との親和性）
・シルバー〜プラチナ: Claude（コード生成・ファイル編集に強い）
```

### 3. ローカルPCにコードを置かない

```
【従来の問題】
・担当者退職 → 環境構築からやり直し
・PC故障 → コード消失
・セキュリティ → コードが個人PCに散在

【このカリキュラム】
・退職 → 新担当がログインするだけ
・PC故障 → 別PCで継続
・セキュリティ → コードは会社のGitHubに集約
```

### 4. 低コスト・低運用負担

| ステージ | ツール費用（目安） |
|---|---|
| ブロンズ | 無料 |
| シルバー | Claude Pro $20/月（推奨） |
| ゴールド | 同上 + API従量課金（少額） |
| プラチナ | Claude API 従量課金 |

```
【外注との比較】
・SIer発注: 初期300万円〜 + 保守月5〜10万円
・このカリキュラム: 教育費 + ツール月数千円

→ 長期的に見て圧倒的なコスト優位性
```

## よくある質問

### Q: プログラミング未経験でも大丈夫ですか？

```
A: はい、ブロンズからスタートすれば大丈夫です。
   Excelが使えるレベルであれば、AIの助けを借りながら
   着実にスキルを身につけられます。
```

### Q: 全ステージを修了しないと意味がないですか？

```
A: いいえ、各ステージで十分な価値があります。
   ・ブロンズだけでも日々の業務効率化が可能
   ・シルバーまでで自社アプリの内製化が可能
   ・必要に応じてゴールド・プラチナへ進めます
```

### Q: 学んだ後、継続的なサポートはありますか？

```
A: 開発環境がすべてクラウド上にあるため、
   ・困ったらAI（Claude Code）に質問
   ・コードはGitHubに残っているので引き継ぎ容易
   ・必要に応じて追加のコンサルティングも可能
```

### Q: セキュリティは大丈夫ですか？

```
A: はい、以下の対策を取っています。
   ・コードはGitHub（企業管理下）に集約
   ・Supabaseは業界標準のセキュリティ
   ・機密データはマスキング処理
   ・医療系など特殊要件はハイブリッド構成で対応可能
```
