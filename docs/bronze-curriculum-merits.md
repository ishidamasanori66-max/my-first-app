# ブロンズカリキュラム：技術選定とメリット総括

## 概要

本ドキュメントは、中小企業向けAI伴走型開発教育「ブロンズカリキュラム」における技術選定の根拠と、各視点からのメリットをまとめたものです。

---

## カリキュラム全体における位置づけ

| ステージ | 技術スタック | 環境 | AI伴走 | ゴール |
|---|---|---|---|---|
| **ブロンズ** | **Python + Pandas** | **Google Colab** | **Gemini** | **Excel業務の自動化** |
| シルバー | React (Vite) + Supabase | Codespaces | Claude Code | 業務アプリ開発 |
| ゴールド | + Edge Functions + 外部API連携 | Codespaces | Claude Code | システム統合 |
| プラチナ | Python + LangChain + Claude API + pgvector | Colab | Claude API | AI自律化 |

**ブロンズは「プログラミング未経験者の最初の一歩」**

## ブロンズの目標

```
「面倒なExcel業務を5分で終わらせる」

・手作業のデータ処理を自動化
・Excelでは難しい大量データの処理
・定期レポートの自動生成
・データの可視化（グラフ作成）
```

### 解決する現場の課題

```
【よくある状況】
・毎月同じExcel作業を繰り返している
・複数ファイルのデータを手作業で結合
・大量データでExcelが重くなる
・集計ミスが発生する

【ブロンズで解決】
・定型作業をコード化して自動実行
・複数ファイルを一括で処理
・大量データも数秒で処理
・一度書いたコードは何度でも使える
```

### 他言語との比較

| 言語 | 評価 | 理由 |

| Excel VBA | △ | 汎用性が低い、古い |

### Python の優位性

```
1. データ処理のデファクトスタンダード
   → Pandas, NumPy, matplotlib が揃っている

2. 学習リソースが豊富
   → 日本語の書籍・記事・動画が多い

3. カリキュラムの一貫性
   → プラチナ（LangChain）でも Python を使用

4. 求人市場での価値
   → データ分析・AI分野で需要が高い

5. AIとの相性
   → LLM が Python コードを生成するのが得意
```

## Pandas とは

### 概要

```
Python のデータ処理ライブラリ

・Excel のシートのような「表形式」でデータを扱う
・フィルタリング、集計、結合などが簡単
・大量データでも高速処理
```

### Excel との対応

| Excel の操作 | Pandas での書き方 |
|---|---|
| ファイルを開く | `pd.read_csv('file.csv')` |
| フィルター | `df[df['売上'] > 10000]` |
| 並べ替え | `df.sort_values('日付')` |
| 合計 | `df['売上'].sum()` |
| ピボットテーブル | `df.pivot_table(...)` |
| VLOOKUP | `df.merge(df2, on='ID')` |

### テーブル思考の習得

```
【ブロンズ】
Pandas の DataFrame = 行と列のテーブル
    ↓
「テーブル思考」を習得
    ↓
【シルバー・ゴールド】
Supabase（PostgreSQL）も同じテーブル構造
    ↓
ブロンズの知識がそのまま活きる
```

## 中小企業での活用例

### 1. 月次売上レポートの自動生成

```
【従来】
1. 各店舗からCSVを受け取る（メール）
2. Excelで1つずつ開いてコピペ
3. 関数で集計
4. グラフ作成
5. 体裁を整える
→ 毎月3時間

【ブロンズ】
1. CSVをフォルダに入れる
2. コードを実行（1クリック）
→ 5分で完成
```

### 2. 顧客リストのクレンジング

```
【従来】
・重複を目視で探す
・電話番号の形式をひとつずつ直す
・空白セルを探して埋める
→ 半日作業

【ブロンズ】
df = df.drop_duplicates()  # 重複削除
df['電話'] = df['電話'].str.replace('-', '')  # 形式統一
df = df.fillna('不明')  # 空白を埋める
→ 1分で完了
```

### 3. 複数ファイルの統合

```
【従来】
・10店舗のファイルを開く
・1つずつコピーして貼り付け
・店舗名の列を追加
→ 1時間

【ブロンズ】
files = glob.glob('*.csv')
df = pd.concat([pd.read_csv(f) for f in files])
→ 数秒で完了
```

### 4. 在庫アラートの自動化

```
【従来】
・毎日在庫リストを確認
・閾値以下を目視で探す
・対象を別シートにまとめる
→ 毎日30分

【ブロンズ】
alert = df[df['在庫'] < df['発注点']]
alert.to_csv('発注アラート.csv')
→ 毎日1分（自動実行も可能）
```

## 注意点・配慮事項

### プログラミング初心者への配慮

```
1. エラーへの恐怖を取り除く
   「エラーは友達、直せば動く」

2. Gemini を頼る文化
   「分からなかったらAIに聞く」が当たり前

3. コピペOKの姿勢
   まず動かす → 後から理解

4. 完璧を目指さない
   「動けばOK」からスタート

5. 小さな成功体験
   最初の1行が動いた喜び
```

### Excel への敬意

```
1. 「Excel はダメ」と言わない
   Excel でやってきたことを否定しない

2. Excel でできることは認める
   適材適所の考え方

3. 最終出力は Excel でも良い
   Python は処理担当、Excel は見せる担当
```

### 挫折ポイントへの対策

| 挫折ポイント | 対策 |
|---|---|
| 環境構築で止まる | Colab で回避 |
| エラーの意味が分からない | Gemini に聞く |
| 何から始めれば良いか分からない | カリキュラムに沿って進める |
| 自分のデータに適用できない | 第5部で実践 |
| 続けるモチベーション | 成功体験を積む |
