## 競合・参考企業分析

### ROIT株式会社

#### 会社概要

```
【基本情報】
・設立：2016年（NTTデータ出身者による創業）
・事業：クラウド専門のシステムインテグレーター
・URL：https://www.roit.co.jp/

【ミッション】
「IT投資効果（Return on IT）の最大化」
→ 社名自体が「Return on IT」から命名

【ビジョン】
「AIクラウドインテグレーターのリーディングカンパニー」

【展開】
・2025年内にシンガポール・上海に現地法人設立予定
・グローバル展開を推進中
```

#### 技術スタック

```
【主要技術】
・Microsoft Dynamics 365（ERP/CRM/SFA/MA）
・Power Platform（Power Apps, Power BI, Power Automate）
・Azure（クラウド基盤）
・生成AI（Microsoft 365 Copilot, Azure OpenAI, ChatGPT）

【特徴】
・Microsoft製品に特化
・エンタープライズ向けの統合ソリューション
・高額なライセンス費用が前提
```

#### サービス内容

```
【7つの事業領域】
1. Dynamics 365 導入・コンサルティング
2. Power Platform 活用支援
3. Azure クラウド構築
4. 生成AI（Copilot/ChatGPT）導入支援
5. BI/データ分析基盤構築
6. IT人材リスキリング・紹介
7. グローバルDX支援

【製造業DXサービス】
・顧客データ、商談、売上、設備稼働状況、品質情報等を可視化
・AIやクラウドを活用した生産効率・品質向上
・3営業日でプロトタイプ提案
・1〜3ヶ月でPoC実施
・「スピード重視で結果にコミット」

【教育・研修サービス】
・Power Platform 研修
・講師は実際の導入コンサルタントが担当
・現場経験に基づいた実践的な内容
```

#### 対象顧客

```
【主なターゲット】
・製造業（特にグローバル展開企業）
・中堅〜大企業
・IT部門を持つ企業
・Microsoft製品への投資が可能な企業
```

### Aratana vs ROIT 比較分析

#### 基本比較

```
項目                ROIT                    Aratana
─────────────────────────────────────────────────────────────
対象顧客            中堅〜大企業            中小企業
IT部門              あり前提                なし前提（共有情シス）
技術スタック        Microsoft中心           OSS中心（Django等）
初期コスト          高い                    低い（無料枠活用）
ライセンス費用      高額（MS製品）          最小限
ローコード          Power Apps              AppSheet
BI                  Power BI                Supabase + 自作
教育アプローチ      リスキリング研修        5段階カリキュラム
講師                実務コンサルタント      （検討中）
```

#### ローコードツール比較

```
【Microsoft Power Platform】
・Power Apps（ローコードアプリ開発）
・Power Automate（ワークフロー自動化）
・Power BI（データ可視化）
・費用：有料（Microsoft 365ライセンス + 追加費用）
・対象：IT部門がある企業

【Google AppSheet】
・ローコードアプリ開発
・ワークフロー機能
・データ可視化
・費用：Google Workspace に含まれる
・対象：中小企業でも導入可能

【共通点】
・非エンジニアでもアプリが作れる
・データドリブンな開発
・業務効率化が目的

【Aratanaの選択理由】
・AppSheetはGoogle Workspaceに含まれる（追加費用なし）
・中小企業が既に使っているツールとの親和性
・ブロンズカリキュラムでの導入ハードルが低い
```

### ROITから学ぶべき点

#### 1. 「投資効果」で価値を語る姿勢

```
【ROITのアプローチ】
・社名自体が「Return on IT」
・「IT投資効果の最大化」を前面に出す
・技術ではなく「効果」で語る

【Aratanaへの示唆】
・「DX教育」ではなく「投資効果」で語る視点
・経営者に響く言葉で価値を伝える
・例：「DX人材育成のROIを最大化」
・例：「IT投資ゼロから始めるDX」
```

#### 2. 実務者が教える研修スタイル

```
【ROITの研修】
・講師は普段から導入コンサルを行う実務者
・現場での導入経験に基づいた知見を提供
・「研修専門講師」ではない

【Aratanaへの示唆】
・カリキュラムの講師も実務経験者が望ましい
・「教科書的知識」ではなく「現場で使える知識」
・Aratana社員自身がDjango+Supabaseで開発している実績
・「共有情シス」での実務経験を教育にフィードバック
```

#### 3. 高速プロトタイピング

```
【ROITのアプローチ】
・3営業日でプロトタイプ提案
・1〜3ヶ月でPoC実施
・「スピード重視で結果にコミット」

【Aratanaとの共通点】
・Phase 2.5「HTMXモックで検証」と同じ発想
・動くものを早く見せて認識ズレを防ぐ
・「業務データ駆動開発」のサイクルと整合

【Aratanaの強み】
・HTMXモックは更に高速（数時間〜1日）
・コード不要で動く画面を作成可能
・中小企業の意思決定スピードに合致
```

#### 4. 段階的な成長パス

```
【ROITの提供価値】
・ローコード（Power Apps）→ プロコード（Azure開発）
・段階的にIT活用度を高める
・リスキリングで社内人材を育成

【Aratanaの提供価値】
・ローコード（AppSheet）→ プロコード（Django）
・5段階カリキュラムで段階的に成長
・最終的に「卒業」できる設計
```

### ROITを参考にしない点

```
【対象外とする要素】

1. Microsoft中心のスタック
   → 中小企業にはライセンス費用が高すぎる
   → Google Workspace + OSSの方が適合

2. 大企業向けのサービス設計
   → IT部門がある前提のサービスは不要
   → 「共有情シス」が差別化ポイント

3. グローバル展開
   → Aratanaの対象は国内中小企業
   → 海外展開は現時点で不要

4. 高額なコンサルティングフィー
   → 中小企業には負担が大きい
   → 教育カリキュラムで内製化を支援
```
