# ユーザー管理システム 操作マニュアル

本ドキュメントでは、Webブラウザからユーザー情報を登録・編集する手順を説明します。

---

## 1. ログイン画面の操作

システムにアクセス後、以下の画面が表示されます。

<!-- HTMLの<img>タグで画像サイズ調整と中央揃えを定義 -->

  <br>

### 操作手順
1. アカウント名入力欄に <kbd>ユーザーID</kbd> を入力します。
2. パスワード入力欄に <kbd>パスワード</kbd> を入力します。
3. <span style="color: #2563eb; font-weight: bold;">[ログイン]</span> ボタンを押下します。

<span style="color: #dc2626; font-weight: bold;">※注意：</span> 連続して5回パスワードを間違えるとアカウントがロックされます。

---

## 2. ユーザー登録手順

ログイン後、ダッシュボードから <kbd>設定</kbd> &rarr; <kbd>ユーザー追加</kbd> へ移動します。

<!-- HTMLの<details>/<summary>タグでアコーディオン表示（折りたたみ）を実現 -->
<details>
<summary><b>【クリックで展開】入力項目仕様・制限事項について</b></summary>

| 項目名 | 必須 | 制約ルール |
| :--- | :---: | :--- |
| **氏名** | ○ | 全角50文字以内 |
| **メールアドレス** | ○ | 半角英数字（RFC準拠） |
| **権限グループ** | ○ | `管理者` / `一般ユーザー` / `閲覧専用` |

</details>

## 3. トラブルシューティング（FAQ）

<details>
<summary><b>Q. 画面が正常に読み込まれない・ボタンが押せない場合</b></summary>

ブラウザのキャッシュが影響している可能性があります。
キーボードの <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> （Macは <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd>）を押して、ハードリフレッシュを試みてください。
</details>
